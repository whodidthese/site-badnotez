## App Review notes

```
Badnotez is a local-only handwriting notebook for iPad. It has no account, sign-in, server, in-app purchase, ads or tracking.

How to review:
1. In the Library, tap Create Notebook, then tap Create.
2. Write or draw with Apple Pencil. Fingers operate the interface: buttons, scrolling, pinch to zoom and swiping between pages.
3. Use the photo button in the toolbar to insert an image, and the text box button to add text.
4. The "…" menu at the top right offers Export Notebook as PDF and Export Current Page (PDF, PNG or JPEG).
5. Settings (the gear in the Library) contains pen colors, highlighter colors, brush sizes, paper colors, Recently Deleted, and import/export of editable .badnotes notebook backups.

Photos access: the app uses the system photo picker (no library permission) and only asks for add-only access when the user saves an exported image to Photos.
```
